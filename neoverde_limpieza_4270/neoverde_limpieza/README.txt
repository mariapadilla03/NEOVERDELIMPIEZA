NEOVERDE — PÁGINA SENCILLA DE LIMPIEZA
======================================

Archivos:
- index.html: contenido de la página.
- css/styles.css: estilos y diseño adaptable.
- README.txt: instrucciones.

Para abrir:
1. Extrae el archivo ZIP.
2. Abre Visual Studio Code.
3. Ve a Archivo > Abrir carpeta y selecciona "neoverde_limpieza".
4. Abre index.html en tu navegador, o usa Live Server si lo tienes instalado.

La página utiliza Bootstrap desde CDN, por lo que se necesita internet para cargarlo.
El diseño es sencillo y usa una ilustración hecha con CSS para no depender de imágenes.
Cambia el correo de ejemplo por el correo que quieras usar.
